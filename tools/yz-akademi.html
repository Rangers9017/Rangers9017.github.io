⚙️ Çalışma Prensibi

Yapay Zeka Nasıl Çalışır?

Bir YZ modeli dört temel aşamadan geçerek "zeka" kazanır. Bu süreç aylar sürebilir ve devasa hesaplama gücü gerektirir.

01
📦

Veri Toplama

Model, metin, görüntü, ses veya sayısal verilerden oluşan dev veri setleriyle beslenir. GPT-4 yaklaşık 1 trilyon token ile eğitilmiştir.

02
🧠

Model Eğitimi

Nöral ağ, geri yayılım algoritmasıyla ağırlıklarını günceller. Her iterasyonda hata payı azalır, tahminler iyileşir.

03
🔬

Değerlendirme

Test veri setiyle doğruluk ölçülür. Overfitting, underfitting gibi sorunlar tespit edilip giderilir. İnce ayar (fine-tuning) yapılır.

04
🚀

Deployment

Model API veya doğrudan servis olarak kullanıma alınır. Gerçek dünya verileriyle izlenir ve sürekli güncellenir.

05
⚡

İnferans (Tahmin)

Eğitilmiş model yeni girdiyi alır, milyonlarca matris çarpımı yaparak çıktı üretir. Bu işlem milisaniyeler içinde gerçekleşir.

06
🔄

Sürekli Öğrenme

RLHF (İnsan Geri Bildirimiyle Pekiştirmeli Öğrenme) ile model, insan tercihlerine göre sürekli geliştirilir.

YZ Kariyerine Başlangıç Rehberi

Sıfırdan 18-24 ay içinde iş bulmaya hazır hale gelebilirsiniz. İşte adım adım yol:

1
Ay 1–2 · Temel

Programlama Temelleri

Python dilini öğrenin. Veri yapıları, döngüler, fonksiyonlar ve OOP konularını pekiştirin. Matematik temellerini (lineer cebir, istatistik, kalkülüs) gözden geçirin.

Python NumPy Pandas Lineer Cebir Olasılık
2
Ay 3–5 · ML Temeli

Makine Öğrenmesi

Gözetimli ve gözetimsiz öğrenme algoritmalarını öğrenin. Scikit-learn ile pratik yapın. Kaggle yarışmalarına katılmaya başlayın.

Scikit-learn Matplotlib Kaggle Feature Engineering
3
Ay 6–9 · Derin Öğrenme

Neural Networks & Deep Learning

PyTorch veya TensorFlow öğrenin. CNN, RNN ve Transformer mimarilerini anlayın. Andrew Ng'nin Deep Learning Specialization kursunu tamamlayın.

PyTorch CNN Transformer Hugging Face
4
Ay 10–14 · Uzmanlaşma

Uzmanlık Alanı Seçin

NLP, Computer Vision veya RL alanlarından birini seçin. Akademik makaleler okuyun, SOTA modelleri reproduce edin. GitHub profilinizi güçlendirin.

LLM Fine-tuning YOLO / SAM arXiv GitHub Portfolio
5
Ay 15–18 · Production

MLOps & Deployment

Docker, Kubernetes ve cloud platformlarını öğrenin. MLflow veya W&B ile deney takibi yapın. FastAPI ile model servisi kurun.

Docker AWS/GCP/Azure MLflow FastAPI
✓
Ay 18–24 · İş Arama

Portföy & Kariyer

En az 3-5 portföy projesi hazırlayın. LinkedIn profilinizi güncelleyin. Mülakatlara hazırlanın: sistem tasarımı, ML kavramları ve kodlama soruları.

LinkedIn LeetCode Sistem Tasarımı Portfolio
